# Admin Threat Monitoring Update v3

- Doctors: Behavior Score removed from the visible list/profile; Overview and Security & baseline profile tabs removed. Activity History remains.
- Threat Monitoring: dark readable doctor cards, Profile label, no Selected Event block, no old Doctor Timeline table. Clicking a doctor card opens that doctor's time-based threat timeline.
- Download generates a report containing the selected doctor's displayed threat details and timeline.
- AI Security Center: Attack Simulation, Start Insider Demo, and Investigation Reports removed. Live Threat Timeline and Recent AI Predictions remain.
- Blood group values use normal table font styling; rare-color emphasis removed.
- Doctor Dashboard and Evidence Vault were not modified.
