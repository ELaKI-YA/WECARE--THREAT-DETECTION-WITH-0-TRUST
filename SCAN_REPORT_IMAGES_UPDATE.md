# Scan Report Images Update

Added the six user-provided scan/report images to the Doctor Scan Reports section.

- CT Abdomen
- CT Brain
- CT Chest
- CT KUB
- CT KUB text report
- USG Abdomen & Pelvis

Click a Scan Reports row, choose **View**, and the attached report image opens in the existing report viewer. The viewer supports Print and Download. The supplied images are stored under `public/assets/scan-reports/`.

No Admin or Evidence Vault files were changed for this update.
