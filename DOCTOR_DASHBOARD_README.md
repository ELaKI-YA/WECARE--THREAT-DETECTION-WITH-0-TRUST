# Updated Doctor Dashboard

- Natural hospital-team image header
- Dynamic doctor position and department from login data
- Dashboard/My Schedule opens by default
- Other modules open only when selected
- Add, edit, view, upload, delete and export support
- Blood group displayed in patient-related records, including rare groups
- Scan and lab report viewer with the supplied demo report images

Run with `npm install`, `npm run seed`, then `npm start`.
